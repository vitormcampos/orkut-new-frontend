# Orkut New — Frontend

**Stack**: React Router v7 (framework mode, SSR), React 19, Vite 8, Tailwind CSS v4, shadcn/ui (base-vega style), TypeScript v6.

## Dev commands

```bash
npm run dev       # React Router dev server
npm run build     # production build
npm run start     # serve production build (react-router-serve)
npm run typecheck # MUST run: react-router typegen && tsc (both, in order)
npm run format    # prettier --write "**/*.{ts,tsx}"
```

No test runner or linter is configured yet.

## Project structure

```
app/
├── root.tsx              # root layout (Layout, App, ErrorBoundary)
├── routes.ts             # flat route config using @react-router/dev/routes
├── routes/               # page components (e.g. home.tsx)
├── components/ui/        # shadcn/ui components (base-vega style)
├── lib/utils.ts          # cn() helper (clsx + tailwind-merge)
└── app.css               # Tailwind v4 CSS, shadcn theme vars, Inter font
```

- Routes **must** be registered in `app/routes.ts` (flat config), not auto-discovered from the `routes/` directory.
- Route files import types from `./+types/<name>` (e.g. `./+types/root`). These are generated by `react-router typegen`.
- Path alias: `~/*` → `app/*`. Use `~/components/ui/button` not `@/...`.

## TypeScript

- `verbatimModuleSyntax: true` — use `import type` for type-only imports
- `strict: true`, `target: ES2022`, `module: ES2022`, `moduleResolution: bundler`
- The `.react-router/types/` directory is gitignored and auto-generated.

## CSS / Tailwind

- Tailwind v4 — CSS-first config via `@import "tailwindcss"` in `app/app.css`. No `tailwind.config.*` file.
- Dark mode via `.dark` class (`@custom-variant dark (&:is(.dark *));`).
- shadcn theme variables defined as CSS custom properties in `app/app.css` (both `:root` and `.dark`).
- Font: Inter Variable (`@fontsource-variable/inter`).

## shadcn/ui

- Style: `base-vega` — uses `@base-ui/react` for primitives (not Radix UI).
- Adding new components: `npx shadcn add <component>`.
- Imports: `import { Button } from "~/components/ui/button"`.
- `cn()` from `~/lib/utils` for class merging. `cva` from `class-variance-authority` for variant props.
- **IMPORTANT**: Base UI does NOT use `asChild`. There is no `asChild` prop on Button or other components. For link-styled buttons, either use the `render` prop from Base UI or style a `<Link>` directly with matching Tailwind classes.
- Installed components so far: `button`, `card`, `input`, `label`, `field`, `separator`, `avatar`, `dropdown-menu`.

## React Router v7

- Routes registered in `app/routes.ts` using flat config: `index()`, `route()` from `@react-router/dev/routes`.
- Page title via `meta` export on each route file:

  ```tsx
  import type { Route } from "./+types/page-name"

  export function meta({}: Route.MetaArgs) {
    return [
      { title: "Page Title | Orkut New" },
      { name: "description", content: "..." },
    ]
  }
  ```

  The `<Meta />` component in `root.tsx` Layout consumes these automatically. Type imports come from `./+types/<name>` generated by `react-router typegen`.
- `<html lang="pt-BR">` — the app is in Brazilian Portuguese.

## API Communication Layer

```
app/lib/api/
├── types.ts      # DTOs: UserDto, LoginRequest, LoginResponse, CreateUserRequest, etc.
├── store.ts      # tokenStore: localStorage wrapper for access/refresh tokens and user
├── client.ts     # api object (get, post, put, delete, upload) + ApiError class
└── auth.ts       # register(), login(), logout(), refreshToken(), forgotPassword(), resetPassword(),
                  # getMe(), updateProfile(), deleteAccount(), uploadPhoto()
```

- Base URL from `VITE_API_URL` env var (default: `http://localhost:5272/api/v1`).
- `api` client auto-attaches `Authorization: Bearer <token>`, auto-refreshes on 401, queues concurrent refresh attempts.
- Errors thrown as `ApiError` (with `status` and `ProblemDetails` from .NET backend).
- `tokenStore` uses `typeof window === "undefined"` guards for SSR safety.
- `api.upload()` for `multipart/form-data` (photo upload).
